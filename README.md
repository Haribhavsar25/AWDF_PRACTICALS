## 🛠️ General Setup & Execution Guidelines

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [MongoDB Community Server](https://www.mongodb.com/try/download/community) (for Practicals 5, 6, 7, 11)
- [Docker & Docker Desktop](https://www.docker.com/) (for Practical 11)

### Standard Running Instructions
Each practical contains an independent or client/server configuration. Follow the dedicated `README.md` inside each practical's folder:
```bash
# Example: Running Practical 1 Frontend
cd "Practical - 1"
npm install
npm run dev

# Example: Running Practical 6 Full-Stack Application
# In backend terminal:
cd "Practical - 6/backend"
npm install
npm run dev

# In frontend terminal:
cd "Practical - 6/frontend"
npm install
npm run dev
```
